# Changelog

All notable changes to the kwtSMS module will be documented in this file.

## [Unreleased]

## [1.1.1] - 2026-11-07

### Fixed
- Bug fixes.

### Added
- Integration name and version sent with requests.

## [1.1.0] - 2026-04-05

### Added
- Log retention policy.
- OTP request and SMS send events for other modules.
- Commerce: low stock alerts, shipping updates and abandoned cart reminders.
- SMS Framework bridge submodule.
- New templates and integration settings.
- GPL-2.0-or-later LICENSE.txt file.

### Fixed
- Bug fixes.

## [1.0.0] - 2026-03-27

### Added
- kwtSMS gateway integration with login and credential management.
- Bulk sending.
- OTP login and two-factor authentication.
- Password reset via SMS.
- User registration SMS notifications.
- Admin UI: Dashboard, Settings, Gateway, Templates, Integrations, Logs, Help.
- SMS templates with Drupal Token integration.
- SMS logging with filtering and CSV export.
- Dashboard with SMS stats.
- Daily sync.
- Arabic translations and RTL support.
- Drupal Commerce order notifications (kwtsms_commerce submodule).
